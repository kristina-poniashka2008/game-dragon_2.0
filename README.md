# Рыцарь против Дракона

Обновлённая браузерная игра на HTML, CSS и JavaScript. Запускается локально — установка библиотек не нужна.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Нажмите «Удар мечом», «Защититься» или «Суперудар».

## Управление
- `1` — обычный удар мечом
- `2` — поднять щит на следующую атаку
- `3` — суперудар

## ООП
- `Dragon` — здоровье дракона, обычные удары и огненное дыхание.
- `Player` — здоровье рыцаря, атака, суперудары и прочность щита.
- `Game` — очередь ходов, бой, эффекты, журнал и завершение игры.

## Что сделано
- Рыцарь и дракон нарисованы CSS-фигурами, без внешних картинок.
- Огненное дыхание создаётся частицами на Canvas.
- Есть анимации атаки, получения урона, поднятия щита.
- Отображаются здоровье, прочность щита и оставшиеся суперудары.
- Игра адаптируется под мобильный экран.
- Внешние библиотеки не нужны. Шрифт из Google Fonts используется только при наличии интернета.

Исходный файл `игра.py` сохранён в архиве для связи с первоначальной ООП-версией.
